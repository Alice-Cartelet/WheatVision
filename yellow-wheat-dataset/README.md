# 黄化强化补充数据

12 张内置 imagegen 生成的整株小麦苗图，45 个逐叶实例。沿叶片走向辅助提取多边形，再核对标注叠加图。极细的叶尖和茎基部边界是近似标注。橙线为黄化叶，绿线为正常叶。生成提示词见 `generation-prompts.txt`。

每片叶标一条 YOLO 分割多边形。明确黄尖、黄边、黄斑或干枯的整片叶标为 `1 yellowed_leaf`，浅嫩绿但未见明确黄化的叶标为 `0 healthy_leaf`。逐图预期数量见 `manifest.csv`。

8 张加入整株训练，4 张来自另一个生成批次，加入验证。执行项目根目录的 `train_yellow_wheat.py`，合并后为 22 张训练图、8 张验证图和原有 4 张留出测试图。脚本从当前整株 `best-count.pt` 开始微调，默认训练 25 轮，输出至 `runs/wheat-yellow`。可用 `--prepare-only` 生成数据清单而不训练。

新旧权重可以用项目根目录的 `evaluate_whole_wheat.py` 在原留出图上对照。请重点检查黄化叶数，以及全绿图有无误报、轻微黄尖有无漏报。这批数据全部为合成图，实际效果仍需独立实拍整株验证。
