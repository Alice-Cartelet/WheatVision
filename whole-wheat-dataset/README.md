# 整株小麦苗演示数据

22 张单株整苗图，87 个逐叶 YOLO 分割标注。每张图保留叶尖、叶身和茎基部。叶片的可见边界为多边形，一片叶一行。盆土和共用茎基部不单独计数。

- `0 healthy_leaf` 表示未见明确黄化。
- `1 yellowed_leaf` 表示有可见黄化或褐色干枯，局部黄尖仍与同一片叶合并。
- 训练集 14 张，验证集 4 张，测试集 4 张。新图按生成批次划分，六张旧整株合成图只用于训练。全部图均为合成图，没有单叶特写。
- `manifest.csv` 记录每张图的预期正常和枯黄计数。`preview-01.jpg` 至 `preview-04.jpg` 是新图标注叠加，绿线为正常，橙线为枯黄。
- `generation-prompts.txt` 记录图像生成提示词。新图由内置 imagegen 生成，沿每片叶人工指定走向后提取轮廓，再检查叠加效果。细叶尖和叶片相接处是近似标注。

在 PyCharm 运行项目根目录的 `train_whole_wheat.py` 可从通用 YOLO11n-seg 预训练权重开始。结果默认写到 `runs/wheat-whole/weights/best.pt`。用测试集逐张检查正常数、枯黄数和占比。要验证实拍识别效果，仍需独立拍摄和标注整株小麦。
